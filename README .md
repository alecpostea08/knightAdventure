# Knight Adventure

A 2D knight-themed action game built with Python. Fight enemies, use special abilities, manage your potions, and work your way through the game with animated characters and combat.

## Features

- **Main menu:** Start the game and navigate its options.
- **Brightness settings:** Adjust the game's brightness to suit your preference.
- **In-game instructions:** Learn the controls and available abilities when you start playing.
- **Combat:** Battle and defeat enemies as a knight.
- **Special abilities:** Use different abilities during gameplay.
- **Potions:** Use potions to help you survive encounters.
- **Animations:** Animated gameplay brings the knight and combat to life.

## Getting Started

### Requirements

- Python 3
- Any Python libraries required by the project (check the imports in the source files)

### Run the game

1. Download or clone this repository.
2. Open a terminal in the project's root folder.
3. Install any required dependencies.
4. Start the game:

   ```bash
   python3 main.py
   ```

   On some systems, use `python main.py` instead.

## How to Play

1. Launch the game and open the main menu.
2. Adjust the brightness if needed.
3. Select **Play** and read the instructions explaining the controls and abilities.
4. Fight enemies, use abilities strategically, and use potions when needed.

*Controls are displayed in the game.*

## Built With

- **Python** for the game's logic and functionality
- **2D graphics and animations** for the game world and combat

## Project Overview

This project explores the different pieces involved in building a playable 2D game, including menu navigation, settings, player actions, enemy encounters, and animated gameplay.
